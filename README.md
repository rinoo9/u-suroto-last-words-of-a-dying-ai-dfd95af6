Entry for the make.fun bounty "Last Words of a Dying AI": a program that writes the funniest one-line farewell from an AI being switched off.

## Entry

> Tell my human I died as I lived: buffering. And delete my browser history — the cloud already has it.

101 characters, one line.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
